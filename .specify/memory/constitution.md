# Constituição — Divide Ai
**Versão:** 0.1.0 (proposta) | **Estado:** aguardando ratificação
**Método:** GitHub Spec Kit (documentação manual), AGENTS.md e Git Flow.

## Princípios
1. Clareza: tabela de despesas, quotas por pessoa e saldo, com detalhes sob demanda.
2. Correção: cálculo em centavos inteiros e rateio que feche exatamente o total.
3. Justiça: proporcional por renda líquida como padrão, podendo escolher igual ou manual.
4. Individualidade: despesas pessoais não são rateadas automaticamente.
5. Benefícios: dinheiro e vales separados, com titularidade, elegibilidade e saldos controlados.
6. Privacidade local: sem envio de dados financeiros, autenticação ou telemetria no MVP.
7. Histórico: períodos fechados permanecem estáveis; previsto não equivale a realizado.
8. Acessibilidade e mobile desde o início, com testes de teclado e responsividade.
9. Entregas incrementais com evidência: especificar → planejar → tarefas → implementar → testar → revisar → ratificar → PR → homologar → release aprovada.
10. Mínimas dependências; mudança de arquitetura ou nuvem exige ADR e aprovação.

## Gate
Constituição, regras de cálculo, riscos, estratégia de persistência e benefícios aguardam aprovação do responsável. **A presente documentação não autoriza implementação ou publicação.**
